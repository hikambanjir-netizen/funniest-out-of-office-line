One line of out-of-office auto-reply, written to be set by a real person: the sender has run away to join the circus, and the twist is that the clowns covering the inbox reply to email faster than the sender ever did. It is a single line of 103 characters, produced deterministically by `main.py` using only the Python standard library.

## Run it

```sh
python3 main.py
```

This writes the entry line to `entry.txt` (next to `main.py`) and to `/output/entry.txt`, with no trailing newline.
